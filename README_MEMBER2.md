This workspace covers Member 2 responsibilities:

- Results storage support
- Reporting/dashboard starter
- Testing and documentation support

## Important Git workflow

This is a starter scaffold. If the main GuardX repository already exists, **clone it instead of running `git init` again**.

Typical workflow:

```bash
git clone https://github.com/prarthuhs97-stack/GuardX.git
cd GuardX
git checkout -b member2-scoring-comparison-regression
```

Copy these files into the cloned repository, review them, then commit and push.

Do not commit:
- `.venv/`
- `.env`
- real secrets
- private datasets
- generated databases or logs
